Gerador de Vídeos com IA

Crie vídeos de até 1 minuto a partir de um tema: roteiro, imagens, narração e legendas gerados por IA.

Ver código no GitHub Ler a documentação

Como funciona

1

Roteiro

O Claude divide o tema em cenas com narração e descrição visual.

2

Imagens

O Stable Diffusion gera uma imagem para cada cena.

3

Narração

O edge-tts cria a voz em português, sem custo.

4

Montagem

O moviepy junta tudo com zoom suave e legendas.

Como usar

git clone https://github.com/equipetivelox-jpg/geraia.git
cd geraia
pip install -r requirements.txt

export ANTHROPIC_API_KEY="sua-chave"
python gerador_video_ia.py "Curiosidades sobre o espaço" --saida video.mp4
O gerador roda no seu computador (precisa de Python, ffmpeg e uma chave da API da Anthropic). Esta página é apenas a apresentação do projeto.
